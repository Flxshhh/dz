# Учёба — расписание, ДЗ и долги

Веб-приложение (PWA) для вуза: недельное расписание, домашние задания со сроками и долги по предметам.
Без сервера и сборки — чистые HTML/CSS/JS, данные хранятся в `localStorage` браузера.

## Цвета пар в расписании

ДЗ задаётся на одной паре (дата «задано») и сдаётся на другой (срок). Пара, на которой надо сдать ДЗ, подсвечивается:

| Цвет | Статус | Условие |
|---|---|---|
| серый | Висит | сегодня < «задано» — физически ещё нельзя сделать |
| жёлтый | Можно делать | «задано» ≤ сегодня ≤ срок, не отмечено |
| зелёный | Сделано | отмечено галочкой |
| красный | Просрочено | сегодня > срок, не отмечено |

Пример: матан в Пн и Пт. В Пн нажимаешь на пару → «Добавить ДЗ» → срок сам ставится на Пт («к следующей паре»).
С Пн по Пт пятничная пара жёлтая; отметил — зелёная; не сделал к Сб — красная.

## Возможности
- Предметы: цвет, преподаватель, пары по дням недели (включая чётные/нечётные недели), долги.
- Задания: фильтры по статусу, «к следующей паре» одной кнопкой, редактирование.
- Экспорт/импорт JSON — резервная копия и перенос между устройствами.
- Работает офлайн и ставится на телефон («Добавить на главный экран»).

## Запуск
```bash
python3 -m http.server 8000   # затем открыть http://localhost:8000
```
Для телефона удобнее всего GitHub Pages: Settings → Pages → Deploy from branch.
