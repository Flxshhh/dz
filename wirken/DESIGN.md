# Дизайн Wirken — направление и токены

Записано по скиллам frontend-design и unslop. Новые страницы продолжают это направление.

## Направление (unslop)
- **Продукт.** Поставщик инструмента для листогибочных и координатно-пробивных прессов,
  станков для заточки и оборудования — для технологов и снабженцев металлообрабатывающих заводов.
- **Характер.** Точный, инженерный, спокойный.
- **Мир.** Технический чертёж и цех: синие линии на светлой бумаге, сталь.
- **Моменты.** Чертежи инструмента: гиб листа в первом экране, мини-чертежи в каталоге,
  крупный чертёж в шапке раздела.
- **Фирменная деталь.** Короткая бирюзовая полоска «листа металла» — в чертежах и как маркер списков.
  Больше нигде.

## Токены
| Роль | Значение |
|---|---|
| Фон | `#f3f5f7` |
| Поверхность | `#ffffff` |
| Текст: основной / второстепенный / приглушённый | `#142130` / `#4a5768` / `#6b7685` |
| Разделитель | текст на 10% |
| Акцент (кнопка, ссылки, линии чертежей) | `#0b4a8b` |
| Штриховка, тонкие линии | `#8b98a5` |
| Лист металла (фирменная деталь) | `#2aa3c4` |

- Шрифты: IBM Plex Sans 400/500, IBM Plex Mono для дат и подписей на чертежах. Без 600–900.
- Отступы по сетке 4px; между секциями 96px (64px на телефоне).
- Радиусы: кнопки 8, карточки/панели 12–16, вложенные = внешний − отступ.
- Одна кривая анимации `cubic-bezier(.22, 1, .36, 1)`; ховер 150ms, меню 200ms.
- Анимация чертежа на главной идёт циклом (пауза вне экрана); в каталоге — по наведению,
  на тач-устройствах сама.

## Чего не делать
Надписи капсом над заголовками, градиентный текст, одинаковые карточки сеткой,
нумерация 01/02/03 не по порядку, стрелки «→» в конце ссылок, свечения, появление каждой
секции при прокрутке, жирность 700+.
