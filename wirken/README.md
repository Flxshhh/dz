# Wirken — редизайн сайта

Редизайн [wirkenrus.com](https://www.wirkenrus.com): поставки инструмента для листогибочных
и координатно-пробивных прессов. Сайт: https://flxshhh.github.io/Wirken/

Чистые HTML + CSS + немного JS, без сборки. Открыть `index.html` в браузере.

## Идея
Страница оформлена как лист технического каталога: инструмент нарисован линиями чертежа —
со штриховкой сечений, осевой (штрихпунктир) и размерными линиями.

- Цвета фирменные: холодный серый фон, синий логотипа, серый металл, бирюзовый — только для листа металла и фокуса.
- Шрифты: IBM Plex Sans (веса 400 и 500) и IBM Plex Mono для дат и подписей на чертежах — оба с кириллицей.
- Один акцент — синий логотипа (основная кнопка, ссылки, линии чертежей). Бирюзовая полоска «листа металла» —
  фирменная деталь: только в чертежах и как маркер списков.
- Всё выровнено по левому краю, продукция — строками каталога, а не одинаковыми карточками.

## Анимации
- Первый экран: контуры пуансона и матрицы прорисовываются, затем лист гнётся на 90°. Вне экрана анимация на паузе.
- Каталог: у каждой строки свой мини-чертёж — гиб, пробивка, заточка с искрами, пресс-ножницы, нож гильотины.
  Запускается при наведении, на телефонах играет сама.
- Кнопка «наверх» с кольцом прогресса прокрутки.
- При системной настройке «уменьшить движение» анимации отключаются.

Ссылки каталога, новостей, видео и политики ведут на разделы оригинального сайта.

от Damir Sokolovsky ([@heydamir](https://x.com/heydamir)), CC BY 4.0: аудит по списку признаков,
направление из пяти строк, проходы по отступам, цвету, тексту, шрифту, раскладке, деталям и анимации.
