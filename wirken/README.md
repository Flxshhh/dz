# Wirken — редизайн сайта

Редизайн [wirkenrus.com](https://wirkenrus.com) в стиле современных лендингов (21st.dev):
светлая тема в фирменных цветах (белый, синий, серый, бирюзовый) и анимации.

Чистые HTML + CSS + JS — без сборки и библиотек. Открыть `index.html` в браузере.

## Анимации
- появление заголовка по словам из размытия, переливающийся градиентный текст;
- сетка на фоне и световое пятно за курсором, подсветка карточек под курсором;
- анимированные иллюстрации продуктов: гибка листа (W-bend), пробивка отверстий (W-punch), заточка с искрами (W-grind);
- счётчики цифр, появление блоков при прокрутке, бегущая строка;
- луч по рамке блока контактов, кнопка «наверх» с кольцом прогресса прокрутки;
- поиск по сайту — палитра по ⌘K / Ctrl+K.

Учитывается системная настройка «уменьшить движение» (`prefers-reduced-motion`).
